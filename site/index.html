How it works

A confederation in five steps

A confederation is a group of custodians who jointly control one Bitcoin address. No single person can move the coins; the Ethereum contracts verify every Bitcoin block with zero-knowledge proofs.

  1. Request. The initiator lists the custodians and sends a signed request to the operator.
  2. Invitation. The operator publishes an on-chain invitation; each custodian checks its code against the one the operator posts in Telegram.
  3. Installation. Each custodian runs one script on a computer with an NVIDIA GPU and funds a work address with ETH.
  4. Key ceremony. Three distributed key generations create the federation, confederation and Bitcoin keys. Nobody ever holds a whole key.
  5. Custody. Deposits mint sBTC 1:1; withdrawals are signed by the custodian threshold and checked against Bitcoin by ZK proofs.

Trust model

Security & trust

Cryptographic guarantees instead of promises.

FROST threshold signatures
The private key never exists in full. A threshold of custodians must cooperate to sign; their key shares never leave their own computers.
ZK view of Bitcoin
Ethereum contracts accept Bitcoin headers only with a zero-knowledge proof of proof-of-work, starting from a fixed checkpoint. No trusted relayer.
Algorithmic withdrawal
Burn the wrapper and receive BTC. The withdrawal is enforced by contracts, not by a person.
Audited by SmartState
SatoshiFi contracts underwent a full audit by SmartState. Every operation is public on-chain.
