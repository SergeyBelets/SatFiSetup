Custodian client

One script installs everything, creates your work address, binds it to your personal wallet and joins the key ceremony. Rerun the same command at any time: finished steps are skipped.

Before you start

  • Computer: Linux x86-64, Windows 10/11 with WSL2, or a Mac with Apple Silicon. At least 30 GB free disk (100 GB recommended). No graphics card is needed for the ceremony.
  • Windows: open PowerShell as administrator, run wsl --install -d Ubuntu, restart, open the “Ubuntu” app and run every command below in it.
  • Ethereum RPC URL with archive access, for example a free Alchemy Ethereum Mainnet app. The script asks for it.
  • Personal wallet (MetaMask or hardware). Give its address to the operator before you start, otherwise the binding is rejected.
